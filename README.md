# Python Full Stack Mini Project

This is a simple project where I tried to connect **basic backend and frontend functionality using Python**.
The main goal of building this project was to understand how real applications work behind the scenes and how user interaction connects with backend logic.

I created this as a **learning project**, so the focus is more on understanding concepts rather than making something perfect or production ready.

---

## What this project does

* Takes input from the user through a simple frontend interface
* Processes the data using Python backend logic
* Returns a response/output based on the given input
* Demonstrates the basic flow of a full-stack style application

This helped me understand how **data moves between frontend and backend** in a very simple way.

---

## Why I made this

I am currently learning programming and web concepts, and I wanted to build something that is **more than just small console programs**.
So I tried making a mini project where:

* I could apply Python in a practical way
* I could understand backend–frontend connection
* I could learn by building instead of only watching tutorials

This project is part of my **learning journey in development and AI**.

---

## Technologies used

* Python
* Basic programming concepts (functions, conditions, input/output, logic building)
* Simple frontend interaction (minimal UI structure)

No advanced frameworks are used here because the goal was to **learn the fundamentals first**.

## How to run this project

1. Make sure Python is installed on your system.

   ```bash

   ```
3. Open the project folder in terminal or VS Code.
4. Run the main Python file:

   ```bash

   ```
